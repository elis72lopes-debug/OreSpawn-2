# OreSpawn 2 — Minecraft Java 1.12.2

Projeto inicial de mod Forge para Minecraft Java 1.12.2.

## Compilação pelo GitHub Actions

1. Crie um repositório no GitHub chamado `OreSpawn2`.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. Abra a aba **Actions**.
4. Se solicitado, habilite os workflows.
5. Execute **Build OreSpawn 2** em **Run workflow**, ou faça um commit.
6. Quando terminar, abra a execução e baixe o artefato `OreSpawn2-1.12.2`.

O arquivo JAR estará dentro do artefato baixado, na pasta `build/libs`.
